# Обращение к ревьюверу

Задания 1, 5, 6 оформлены в форме Architecture Decision Log записей с разметкой взаимодействий в mermaid формате. Рендеры Drawio схем тоже сделаны.

Пошел таким путем по причинам
1. самому лучше понять схему взаимодействий сервисов
2. mermaid дает более качественный рендер чем drawio
   * ~~drawio нужен для дизайнеров~~

## Вопрос к ревьюверу:
 - На примере задания 5 видно, что схема кратно усложняется. Это приводит к тому, что становится похожей на паутину, нечитабельна. Получается, что маломальски сложная организация сервисов плохо документируется. Как в реальной жизни рисуют схемы для подобных систем? Как сделать мою схему более читабельно?
